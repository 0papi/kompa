# Welcome to Kompa

Kompa is a platform that provides a marketplace for real estate comparable data listings. A realtor or real estate agent with comparable data can create a provider account on Kompa and create listings for their properties. Users can browse and search for properties based on various criteria such as location, price, and amenities. Kompa also provides tools for realtors to manage their listings and track their performance.
On the other hand, a consumer can create a user account on Kompa and search for properties based on their preferences. Users can also leave reviews and ratings for properties they have visited or purchased.
